# Data

## Layout

```
data/
├── raw/                        original downloaded datasets
├── splits/                     train/test CSVs
├── features/                   computed feature matrices
└── cifs/
    ├── training/               main CIF set (~478 OBELiX structures)
    ├── zeo_outputs/            .res and .volpo files from Zeo++ runs
    ├── cleaned/                partial occupancy resolved by snapping to dominant species
    ├── ordered/                partial occupancy resolved by pymatgen supercell ordering
    └── test_candidates/        CIFs for materials you want to predict
```

## Splits (currently at root, used by FINAL scripts)

The combined, cleaned dataset after merging OBELiX and Liverpool, removing non-RT measurements, duplicates, and 32 unparseable glassy entries. Test set extracted before any feature work.

| File | N | Description |
|---|---|---|
| `comp_train.csv` | ~709 | All training entries — OBELiX + Liverpool. Columns: id, composition, log_conductivity, source |
| `comp_test.csv` | 120 | Held-out test set. Same columns. |
| `struct_train.csv` | ~339 | **Subset of comp_train** where a CIF was also available (from OBELiX archives or matched via Materials Project). Every entry here also appears in comp_train. |
| `struct_test.csv` | ~68 | **Subset of comp_test** with CIFs. Same relationship to comp_test. |

**Why two splits?** The full composition set (comp) uses formula-only features and can include all 829 entries. The structure set (struct) is the intersection of those entries with known crystal structures — needed for Tier 2 and Tier 3 features. Roughly half the Liverpool entries had no CIF match, and some OBELiX entries also failed to match, so struct is ~40% smaller than comp.

## CIFs

### `cifs/training/` (currently `cifs/` at root — 1430 files)

The main training CIF set. Contains `.cif` files for OBELiX entries, plus `.res` and `.volpo` sidecar files generated by Zeo++. Files are named by their entry ID (e.g. `00x.cif`). These IDs correspond to the `id` column in the splits CSVs.

### `cifs/zeo_outputs/` (to be split out of `cifs/training/`)

The `.res` and `.volpo` files generated by Zeo++. Currently mixed into `cifs/` alongside the `.cif` files. Separating them makes it clear which files are inputs (CIFs) and which are computed outputs (Zeo++).

### `cifs/cleaned/` (currently `cifs_cleaned/`)

CIFs with partial occupancy resolved by Option 1: snap each site to the dominant species, drop sites below 10% occupancy. Simple but physically wrong for highly disordered structures. Only gained 6 extra Zeo++-parseable structures over the raw CIFs.

### `cifs/ordered/` (currently `cifs_ordered/`)

CIFs with partial occupancy resolved by pymatgen's `OrderDisorderedStructureTransformation` — builds a supercell and uses Ewald energy minimization to find the most physically reasonable atomic arrangement. More principled but can produce large supercells and still fails on heavily disordered structures (~56 failures).

### `cifs/test_candidates/` (currently LLZO/LGPS/Li6PS5Cl .cif files at root)

CIF files for materials you want to predict conductivity for — fetched from Materials Project at runtime by the FINAL scripts. Currently at root because the scripts write them there. Not training data.

| File | Formula | Source |
|---|---|---|
| `LLZO_mp.cif` | Li₇La₃Zr₂O₁₂ | MP mp-942733 |
| `LGPS_mp.cif` | Li₁₀GeP₂S₁₂ | MP mp-696138 |
| `Li6PS5Cl_mp.cif` | Li₆PS₅Cl | MP mp-985592 |

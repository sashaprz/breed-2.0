# Data-driven Prediction of Ionic Conductivity in Solid-State Electrolytes with Machine Learning and Large Language Models

## TL;DR
Kim et al. (2026) augment OBELiX with 178 computationally generated crystal structures (USPEX genetic algorithm + CHGNet MLFF relaxation) to build a 499-entry dataset, then compare stoichiometric-feature GBR, combined-feature GBR, and instruction-tuned LLMs (Mistral-7B, Qwen3-8B) for RT log₁₀(σ) prediction. Mistral-7B achieves MAE=0.798, outperforming GBR (MAE=1.108), by encoding composition and crystallographic disorder as text — bypassing the integer-occupancy limitation of GNNs. Oxygen mole fraction is the #1 SHAP feature for GBR.

## ML method
- **Architecture**: Three model classes — Gradient Boosting Regressor (GBR), GBR with structural features, fine-tuned LLMs (Mistral-7B, Qwen3-8B)
- **Features / inputs**:
  - GBR stoichiometric: elemental mole fractions and derived stoichiometric ratios; SHAP #1 feature is oxygen mole fraction
  - GBR combined: stoichiometric features + Zeo++ probe-occupiable accessible volume (POAV) as a geometric descriptor
  - LLMs: textual representation of composition, crystal class, fractional site occupancies — encodes disorder natively as text where GNNs cannot
- **Target variable**: Room-temperature log₁₀(σ) in S/cm
- **Training data**: 499 CIFs — OBELiX (321) + 152 structures generated by USPEX crystal structure prediction relaxed with CHGNet + 26 from Materials Project / OQMD; augmentation targets OBELiX LiIon-dataset entries that lack experimental CIFs
- **Train/test split**: Inherits OBELiX leakage-free Monte Carlo split (composition/paper grouping)
- **Performance**:
  - GBR stoichiometric: Test MAE=1.108 log₁₀(S/cm)
  - GBR combined (stoich + structural): Test MAE=1.172 log₁₀(S/cm) — slightly worse than stoich-only
  - Mistral-7B: Test MAE=0.798 log₁₀(S/cm) — best result
  - Qwen3-8B: SRCC=0.849 (Spearman rank correlation; MAE not reported)
- **Best prior ML result on same dataset**: OBELiX paper RF MAE=1.59 (without augmentation); GBR here improves substantially by augmenting training data

## Materials / chemistry
- Mixed material classes: all OBELiX structural families (garnet, sulfide, halide, argyrodite, NASICON) plus computationally generated structures
- USPEX structures: generated from stoichiometries taken from LiIon-dataset entries lacking CIFs; genetic algorithm crystal structure prediction followed by CHGNet MLFF relaxation; provides 152 new CIF entries
- Partial occupancy: the key advantage of LLMs is that fractional occupancies can be encoded as text (e.g., "Li₀.₇ occupancy at Wyckoff 24d"), circumventing GNNs' requirement for integer occupancies

## Bottleneck / problem identified
LLMs outperform gradient-boosted models by ~30% in MAE, but the mechanism is opaque. SHAP analysis cannot be applied to LLM internals. The field now faces a fundamental interpretability–performance trade-off: the best-performing model (LLM) is the least interpretable.

A secondary finding: adding structural features (Zeo++ POAV) to GBR slightly degrades performance relative to stoich-only GBR, suggesting the geometric feature introduces noise or collinearity given the small training set.

## Relevance to BREED
- **Benchmark**: Mistral-7B MAE=0.798 vs. BREED GBT MAE=1.192 — a 33% relative improvement on comparable data. LLM fine-tuning is the most clearly superior approach identified so far.
- **GBR comparison**: GBR stoich MAE=1.108 on the augmented 499-CIF dataset vs. BREED 1.192 on the 599-entry full set — datasets differ (augmentation adds 178 structures to the 321-CIF subset), making direct comparison uncertain. Not a confirmed defeat for BREED.
- **Feature hint**: Oxygen mole fraction as the #1 SHAP feature. Check whether BREED's current feature set captures this explicitly or only implicitly via element counts. An explicit O-fraction feature may be worth adding.
- **Data augmentation**: USPEX+CHGNet structure generation is a concrete route to expand BREED's CIF-backed training data. Adds ~50% more CIF entries.
- **Zeo++ negative result**: Adding geometric features (POAV) to a small dataset can hurt performance — informative for BREED's feature engineering decisions.
